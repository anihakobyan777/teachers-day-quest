### WEBSITE DESCRIPTION

**Project Overview:**
This is an interactive web-based Teachers' Day Quest created by the students of 12th AI Grade (12-րդ ԱԲ դասարան). The website serves as a special interactive greeting application designed to celebrate our teachers on Teachers' Day with humor, warm memories, class jokes, and personalized quiz challenges.

**Core Concept & Experience:**

* **Interactive Landing Page («12-րդ ԱԲ-ի Հատուկ Գործողություն»):** Visitors are welcomed with an engaging dashboard where teachers can select their name to launch their custom quiz session.
* **Personalized Quizzes:** Each teacher has a dedicated quest page containing 4 fun, nostalgic, or subject-related multiple-choice questions reflecting real classroom moments, unique quotes, and class dynamics.
* **Emotional Endings & Gratitude:** Completing each quest unlocks a heartwarming, personalized thank-you message and holiday greeting dedicated to that specific teacher.

**Key Features & What Makes It Stand Out:**

* Fully multilingual UI (Armenian, English, Russian) matched to respective subject teachers.
* Clean, intuitive grid navigation with interactive buttons.
* Personalized inside jokes and high emotional value for the entire teaching staff.
* Seamless responsive design optimized for mobile and desktop screens.
